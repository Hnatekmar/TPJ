# Mirage Language Documentation

This directory contains the technical documentation for the Mirage programming language.

> **Note:** Most documentation was originally written in Czech. We are in the process of translating it to English.

## Current Documentation

| File | Language | Description |
|------|----------|-------------|
| `main.tex` | Czech | Main language specification document (LaTeX) |
| `automat.tex` | Czech | Finite automata theory (LaTeX) |
| `cisla.tex` | Czech | Number representation (LaTeX) |
| `identifikator.tex` | Czech | Identifier rules (LaTeX) |
| `slova.tex` | Czech | Reserved words (LaTeX) |
| `ebnf.txt` | — | EBNF grammar notation |
| `gramatiky/` | JSON | Grammar definitions in JSON format |
| `obrazky/` | — | Diagrams and images |
